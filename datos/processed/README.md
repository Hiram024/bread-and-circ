# Datos derivados y trazabilidad

- `<año>/municipio_edad.csv`: totales agregados por año/entidad/municipio/edad.
- `<año>/municipio_edad_sexo.csv` y `municipio_edad_tipo_seccion.csv`: agregación descriptiva de sexo y tipo U/M/R.
- `<año>/municipios_nombres.csv`: claves y nombres observados.
- `<año>/auditoria.json`: origen, hash, controles, faltantes, tamaños.
- `serie_municipio_edad_2009_2024.csv`: formato largo del panel.
- `matriz_modelo_6_anios.csv`: panel ancho con tasas, atributos y flag `apto_modelo`.
- `municipios_auditoria_identidad.csv`: variaciones nominales, heurístico, no equivalencia territorial oficial.

La razón de `SV/(SV+NV)` excluye `NS`. No se consideran mediciones individuales ni un panel longitudinal de personas.
