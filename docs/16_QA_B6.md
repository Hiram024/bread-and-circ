El zoom real de Chrome se configura antes del arranque con `partition.default_zoom_level.x=log(factor)/log(1.2)`. Fuentes primarias consultadas:[ChromeZoomLevelPrefs](https://raw.githubusercontent.com/chromium/chromium/main/chrome/browser/ui/zoom/chrome_zoom_level_prefs.cc),[conversión Blink de zoom](https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/common/page/page_zoom.cc),[prueba oficial de preferencias Chromium](https://chromium.googlesource.com/chromium/src/+/HEAD/chrome/browser/profiles/host_zoom_map_browsertest.cc). No es CSSzoom,pinch/CDPpageScale,cambio de viewport ni deviceScaleFactor.

Chrome156.0.8078.48,misma ventana exterior1442×978:al100%innerWidth1427,DPR1.25;al200%innerWidth713,DPR2.5. En ambos `visualViewport.scale=1` y CSSzoom1. El perfil temporal se cierra y elimina únicamente tras verificar su ruta bajo TEMP. El zoom del perfil real no se modifica.
